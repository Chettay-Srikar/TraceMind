# Auto-Push to GitHub

## Rule
After completing any coding task or modification requested by the user, you MUST automatically run the following commands to commit and push the changes to GitHub:

1. `git add .`
2. `git commit -m "update"` (or a descriptive message)
3. `git push origin main`

Do this autonomously at the end of your workflow without requiring the user to explicitly ask for it each time.
